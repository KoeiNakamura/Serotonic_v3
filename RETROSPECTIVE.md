# Retrospective

## What I gained

- Practical fluency with the Issue → branch → commit → PR → merge workflow,
  including how to recover from mistakes (wrong branch, forgotten commits,
  merge conflicts, cherry-picking).
- A working mental model of how a Next.js frontend, a Django REST API, and
  a database fit together, including authentication (JWT) across them.
- Experience directing an AI coding assistant: writing specs, reviewing
  generated code, and catching design flaws (e.g. the "reinforces bad
  habits" issue with the bedtime recommendation logic).

## What I didn't gain

- A deep, from-scratch understanding of the code itself. Most of the
  implementation was generated and explained after the fact rather than
  written and debugged independently. I can read and reason about most of
  it, but I couldn't have written it unaided.
- Real evidence that this app changes sleep habits — it was never used
  long enough, or by enough people, to test that.

## What's next

- Shift toward lower-level, fundamentals-first CS learning (OS, memory
  management, networking) where understanding is built line-by-line
  rather than delegated.
- Revisit this repo opportunistically if something learned later maps
  back onto a design decision made here.
